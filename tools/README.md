# tools —— 本地测试 / 验证脚本

本目录存放**不依赖 Home Assistant** 的测试与验证脚本。
测试需要的 `SESSION / USER_NO / METER_NO / METER_TYPE` 均**在运行时由用户输入**
或从本地 HAR 快照自动提取，脚本内没有任何预填凭据。

## 1. verify_session.py —— SESSION 有效性验证

**作用**：确认抓包得到的 SESSION 仍有效、当前网络能访问泰能网关，
并在结尾给出可直接填入 HA 集成的「户号 / 表号 / 表类型」。

**前提**：
- 在家庭宽带 / HA 所在局域网内运行（公司网络、云服务器、代理会被网关 403）。
- `pip3 install requests`

**运行**（交互式，脚本会逐项询问）：
```bash
python3 tools/verify_session.py
```

**询问项**：
| 输入项 | 说明 |
|---|---|
| `SESSION` | **必填**。抓包得到的 Cookie 值，形如 `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` |
| `户号` | 可留空 → 自动取公众号默认用户 |
| `表号` | 可留空 → 自动取默认用户的表 |
| `表类型` | 可留空 → 默认 `17` |

**判定方法**：
- 步骤 1 用真 SESSION 调 `getBindUserInfo` 成功 → SESSION 有效；
- 步骤 3 用全 0 的假 SESSION 调同一接口被拒 → 证明服务端确实校验 SESSION。

**常见结果**：
| 现象 | 含义 | 处理 |
|---|---|---|
| `网关拒绝（出口 IP 被拦截）` | 403 被网关拦 | 关闭代理、换回家庭宽带重试 |
| `业务失败 … responseCode=…` | SESSION 失效 | 在公众号里重新打开「用能分析」抓新包 |
| 网络异常/超时 | 本机网络不通 | 检查 DNS/防火墙 |

> 个别家庭网络存在代理/抓包工具证书劫持，如遇 TLS 校验失败可临时执行
> `VERIFY_SSL=0 python3 tools/verify_session.py`（PowerShell: `$env:VERIFY_SSL='0'`）。

## 2. test_cumulative_reading.py —— 口径 / 阶梯离线验证

**作用**：用仓库根目录的 `channel-*.har.json` 抓包快照，喂给
`custom_components/qingdao_taineng_gas/coordinator.py` 的**真实计算函数**，
并依据账单历史核对**抄表间隔与阶梯用量**，不依赖 HA 环境。

计费口径：
- 「本账期累计用量」= 官方抄表日之后、已结算日的用量之和（含/不含抄表当天
  由 `include_base_day` 决定，两种都测）
- 「上个账期累计表读数」= 官方读数（抄表日更新）
- 「燃气总用量」= 官方读数 + 本账期累计用量（total_increasing，供能源面板）
- 「当年累计用量」= 官方年度已结算累计（`cycleCreditQty`）+ 本年度未结算增量
  （户·年累计，每年 1 月 1 日清零）
- 「燃气费单价」= 按当年累计所在档位取 3.54 / 4.12 / 4.99（边际单价，元/m³）

**当前快照（`..._2026_09_07_10_46_57.har.json`）验收对照表**：

| 指标 | 期望值 |
|---|---|
| 官方读数（上个账期） | **207.0 m³** @ 2026-08-30 |
| 本账期累计（默认） | 0.7+0.6+0.6+0.5+0.4+0.3+0.6 = **3.7 m³** |
| 预计当前读数（默认） | **210.7 m³** |
| 本账期累计（校准开关开） | 多含 08-30 的 0.4 → **4.1 m³** / 预计 211.1 m³ |
| 最近一日用量 | **0.6 m³**（2026-09-06） |
| 数据滞后 | **1 天** |
| 上期账单/阶梯 | 07-30(199)→08-30(207) 间隔 31 天，8.0 m³ 全为一阶 3.54 元 → 28.32 元 |
| 年度累计（官方已结算） | 2026 账单合计 145.0 m³ = 接口 `cycleCreditQty` |
| 当年累计用量（默认） | 145.0 + 3.7 = **148.7 m³** |
| 当年累计用量（校准开关开） | 145.0 + 4.1 = **149.1 m³** |
| 燃气费单价（边际） | **3.54 元/m³**（当年累计未跨 228 m³ 阈值） |
| 每日耗气量实体数 | 已结算日 37 个（08-01~09-06，当日 09-07 未结算不生成） |

**运行**（无需联网、无需装 HA，Python 3.9+）：
```bash
python3 tools/test_cumulative_reading.py                 # 默认档 + 校准档都测
python3 tools/test_cumulative_reading.py --include-base-day   # 只测校准档
python3 tools/test_cumulative_reading.py --har <路径>    # 指定 HAR
python3 tools/test_cumulative_reading.py --online        # 追加：用 HAR 内 SESSION 在线重拉核对
```

**它做了什么**：
1. 自动从 HAR 定位 `getBindUserInfo` / `iotBarChart(month/year)` /
   `getBillInfoListPage` 的真实响应（`--online` 时再真实请求一次网关逐条比对）；
2. 以 HAR 文件名内嵌日期（如 2026-09-07）作为参考“今天”，离线可复现；
3. 用与集成实现完全独立的“参考实现”做自洽对照；
4. 快照日期命中已知验收值（2026-09-06 / 2026-09-07）时再做逐项静态比对；
5. 账单核对：每期「读数差 == 用量 == 阶梯量合计」、金额 = Σ各档金额、
   相邻两期抄表间隔与日数据可见部分、年度累计与 `cycleCreditQty` 一致等。

**退出码**：0=全部通过；1=存在不一致；2=缺少 HAR/格式不对。

> 若重新抓包换了日期，脚本会自动跳过“验收”静态比对，只做自洽对照，
> 以公众号实际显示为准即可。`--online` 若提示网关拦截（非家庭宽带），
> 属正常现象，不代表 SESSION 失效。

## 3. 常见问题

**Q：验证脚本会在联网时泄露数据吗？**
不会。请求只发给 `cloudselfhelp-mobile.eslink.cc`，本地仅打印脱敏信息与当前表读数。

**Q：SESSION 过期了怎么知道？**
运行 `verify_session.py`，若步骤 1 返回“业务失败”即为过期；
在公众号重新打开用能分析页面抓新包即可，HA 集成里“选项 → 更新 SESSION”可原地换。
